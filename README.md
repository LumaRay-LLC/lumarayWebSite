# lumaray-site

Static site for LumaRay Software LLC: company home, one page per app, and each app's privacy policy (English + Portuguese). No build step; serve the folder as is.

| Path | Page |
|---|---|
| `/` | LumaRay home |
| `/privacy/` | Index of all privacy policies |
| `/next-chapter/` · `/next-chapter/privacy/` | Next Chapter |
| `/wetab/` · `/wetab/privacy/` | WeTab (Rateio project) |
| `/pantry-stock/` · `/pantry-stock/privacy/` | Pantry Stock (Despensa) |

Every page shares the header with the product tabs (Home · Next Chapter · WeTab · Pantry Stock · Privacy). Company pages use the LumaRay palette from the logo (`assets/logo-tile.jpg`). Product pages take on the app's own identity through the class on `<html>`: `theme-nextchapter` (parchment, Fredoka/Nunito, ink outlines), `theme-wetab` (warm near-black, terracotta, always dark) and `theme-pantry` (iOS grouped lists, system green). The tokens come from each app's asset catalog or `Theme.swift`.

Pages are generated by `python3 tools/build.py`: it writes the home, the product pages and the privacy index, and rewraps each `*/privacy/index.html` around its existing policy text. Edit policy wording directly in those files, and copy, features and layout in the script.

All text is bilingual: elements marked `data-lang-block="en"` / `"pt"` are toggled by `assets/site.js` (EN/PT buttons in the header, `#en` / `#pt` in the URL, then the last choice, then the browser language).

When an app's data handling changes, update its policy and the dates at the top of both languages.
